03 Source Design

ソース設計

プロトタイプでは、実装速度を落とさず、統合時に壊れにくい最小限の設計を置く。重要なのは、各担当が直接相手の内部実装を触らず、契約されたinterface、event、Prefab、ScriptableObjectを介して接続できること。

Assembly Definition案

asmdef参照してよいasmdef内容担当
Game.Coreなしinterface、event型、状態機械、汎用Timer。統合担当
Game.DataGame.CoreScriptableObject定義、enum、profile。データ担当 + 統合担当
Game.GameplayGame.Core, Game.Dataプレイヤー、収集、解放、敵、ステージルール。A〜F
Game.PresentationGame.Core, Game.Data, Game.GameplayUI、VFX、Camera、Audio。G
Game.InfrastructureGame.Core, Game.Data, Game.GameplayBoot、SceneLoad、Pool、Input、CompositionRoot。H
Game.DebugTools全Runtime asmdefデバッグ、メトリクス、検証補助。H/G
循環参照禁止。 GameplayがPresentationを参照し始めると、UIや演出の変更がゲームロジックへ波及する。GameplayはEventを発行するだけにし、Presentationが購読する。

主要interface


namespace Game.Core.Contracts
{
    public interface IGameSystem
    {
        void Initialize(GameContext context);
        void Tick(float deltaTime);
        void Shutdown();
    }

    public interface ICollector
    {
        bool CanCollect(Payload payload);
        void AddPayload(Payload payload);
        CollectionSnapshot GetSnapshot();
    }

    public interface IReleasablePayloadSource
    {
        bool HasPayload { get; }
        PayloadBatch TakeBatch(ReleaseRequest request);
    }

    public interface IDamageableByPayload
    {
        HitResult ApplyHitBatch(HitBatch batch);
    }

    public interface IEnemyGauge
    {
        float Normalized { get; }
        bool IsDown { get; }
        GaugeResult ApplyGaugeDamage(GaugeDamage damage);
    }

    public interface IStageGimmick
    {
        void Activate(StageGimmickContext context);
        void Deactivate();
    }
}

主要データ型

型責務保持する値注意
Payload収集済みの1単位。DefinitionId、Power、GaugeDamage、Weight、Element、Shape、Size、Tags。Unity Object参照を持たせすぎない。
PayloadBatch解放時のまとまり。Payload配列、合計威力、属性割合、解放方向。敵への計算はBatch単位で行う。
HitBatch短時間に敵へ当たったヒット群。Hit数、合計ゲージダメージ、合計本体ダメージ、最初/最後の時刻。スーパーナダレ判定に使う。
CollectionSnapshotUIやDebug表示用の保持状態。現在数、容量、カテゴリ別数、合体候補。読み取り専用にする。
ReleaseContext落とす処理の文脈。位置、方向、対象DropZone、倍率、ナダレ中か。ReleaseEmitterへ渡す。
GaugeDamage敵ゲージへ与える減少量。Value、Element、IgnoreBarrier、SourceType。バリア判定を敵側に集約する。

イベント設計

Eventは「完了した事実」の通知として扱う。命令や戻り値が必要な処理はEventにしない。たとえば、敵へダメージを与える処理は IDamageableByPayload.ApplyHitBatch を直接呼び、その結果として EnemyHitBatchEvent を発行する。


// Event naming rule: Past tense for completed facts, Request for commands.
public readonly struct CollectionChangedEvent
{
    public readonly int CurrentCount;
    public readonly int Capacity;
    public readonly IReadOnlyList<PayloadSummary> Payloads;
}

public readonly struct PayloadReleasedEvent
{
    public readonly int PayloadCount;
    public readonly float TotalPower;
    public readonly Vector3 ReleasePosition;
    public readonly Vector3 ReleaseDirection;
}

public readonly struct EnemyHitBatchEvent
{
    public readonly EnemyId EnemyId;
    public readonly int HitCount;
    public readonly float GaugeDamage;
    public readonly float BodyDamage;
}

public readonly struct EnemyDownStartedEvent
{
    public readonly EnemyId EnemyId;
    public readonly float Duration;
}

public readonly struct SuperAvalancheStartedEvent
{
    public readonly EnemyId TriggerEnemyId;
    public readonly float Duration;
    public readonly float SpawnMultiplier;
}

主要クラス責務

Player

クラス責務依存公開するもの
PlayerControllerPlayer全体のFacade。Motor、Collector、Release、Healthを束ねる。PlayerMotor、CollectionBuffer、ReleaseController。Initialize、GetCollectionBuffer。
PlayerInputReader入力を読み、PlayerInputStateを作る。Input SystemまたはUnity標準入力。CurrentInput。
PlayerMotor見下ろし移動、加速度、方向、接地処理。RigidbodyまたはCharacterController。Move(input)、Velocity。
ArmSweepController左右腕の収集範囲、手動/自動スイープ。Collider、PlayerInputState。GetSweepAreas。
PlayerCollector範囲内CollectableをBufferへ入れる。CollectionBuffer、ICollectable。TryCollect。
CollectionBuffer保持Payload、容量、合体候補、Snapshot。PayloadMutationSystem。AddPayload、TakeBatch。
ReleaseController解放入力を受け、PayloadBatchをReleaseEmitterへ渡す。IReleasablePayloadSource、ReleaseEmitter。TryRelease。
PlayerHealth体力、被ダメージ、死亡通知。EventBus。ApplyDamage、IsDead。

Collectable / Payload

クラス責務補足
CollectableEntityフィールド上の物。拾われたらPayloadへ変換され、PrefabはPoolへ戻る。Prefab側のルート契約。
CollectableSpawnSystemステージ上へ物を補充する。SuperAvalanche中はSpawnRateを上げる。
CollectablePoolCollectableEntityのプール。ステージ読み込み時に事前生成。
PayloadMutationSystem保持中Payloadの合体、形状変化、属性付与を処理する。収集中の面白さを作る中心。
FusionResolverFusionRecipeDefinitionから合体可能な組み合わせを判定する。レシピ数が増えても分離可能。
ShapeMorphTracker転がし距離や保持時間でShapeを変える。形状変化の効果を数値化する。

Release / Hit

クラス責務補足
ReleaseEmitterPayloadBatchから落下演出オブジェクトを生成する。演出数の上限を持つ。
DropTrajectoryResolver解放方向、DropZone、ステージ傾きから軌道を決める。後から放物線/直線/吸い込みに変更可能。
ReleasedPayloadProjectile解放された物体の演出と命中判定。一定時間後Poolへ戻す。
HitBatchAccumulator短時間のヒットをまとめる。スーパーナダレ判定に必須。
DamageResolverPayload属性、敵バリア、ダウン状態からダメージを計算する。計算をEnemyControllerから分離。

Enemy / Stage

クラス責務補足
EnemyController敵全体のFacade。Gauge、Barrier、HP、攻撃を束ねる。統合側はこのクラスだけ参照する。
EnemyAttackGauge時間で増加し、Payloadで減少し、0でBreakする。本作の駆け引きの中心。
BarrierControllerダメージ無効範囲、属性無効、弱点条件を判定する。敵別にprofileで差し替え。
EnemyDownStateダウン中の時間、弱点開放、本体ダメージ倍率。SuperAvalancheと接続。
StageControllerステージ内のEnemy、DropZone、SpawnZone、Gimmickを管理する。RunRuleControllerと接続。
StageTiltController敵撃破やボスギミックでフィールドを傾ける。雪崩演出を開始する。
AvalancheFlow傾き方向に物を流す演出と巻き添えダメージを作る。完全物理ではなく制御型。
FieldWeightSystemフィールド上の物量に応じた沈み込みを管理する。ボス戦用。

Update順序

順System内容理由
1InputSystemAdapter入力状態を確定する。以降の処理が同じ入力を見るため。
2PlayerMotor移動と向きを更新する。収集判定前に位置を確定する。
3ArmSweepController / PlayerCollector収集範囲を更新し、物を拾う。移動後の範囲で判定する。
4PayloadMutationSystem保持中の変化を処理する。解放前に最新状態を反映する。
5ReleaseController解放入力があればBatchを作る。変化済みPayloadを落とす。
6HitBatchAccumulator命中を束ねてEnemyへ送る。大量ヒットを1フレームごとに分散しすぎない。
7EnemySystemゲージ、ダウン、攻撃、死亡を処理する。ヒット結果を受けて敵状態を確定。
8StageGimmickSystem傾き、崩落、ボスギミックを処理する。敵撃破結果を受ける。
9PresentationSystemUI、VFX、Audio、Cameraを更新する。確定したゲーム状態を表示する。
