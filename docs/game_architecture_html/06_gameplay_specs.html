06 Gameplay Specs

ゲームメカニクス仕様

このページでは、プロトタイプで実装するゲームシステムを、実装可能な単位まで分解する。各仕様は、最初から製品版の完成形を狙うのではなく、コア体験の検証に必要な最小単位として定義する。

1. 収集システム

項目仕様調整パラメータ検証観点
収集範囲プレイヤー周囲または腕Collider内のCollectableを検出する。半径、角度、左右腕幅、検出間隔。狙って拾えるか、広すぎて自動回収にならないか。
吸い込み拾われた物は即消滅ではなく、短時間プレイヤーへ吸い込まれる。吸い込み時間、軌道、速度。収集した手応えが見えるか。
保持CollectionBufferにPayloadとして保持する。最大容量、重量上限、カテゴリ別上限。集める量に意味があるか。
保持Visual保持数に応じてプレイヤー周辺に簡易Visualを出す。表示上限、密度、揺れ、追従速度。大量に持っている感じが出るか。
補充Stage上の物が一定数以下になるとSpawnZoneから補充する。最大配置数、補充間隔、カテゴリ比率。常に物で溢れる印象が出るか。

収集時の優先ルール

  1. プレイヤーの収集範囲内に入ったCollectableを候補にする。
  2. CollectionBufferの容量を確認する。
  3. 容量不足なら、軽い物だけ拾う、古い物を落とす、または拾わないのいずれかを選ぶ。
  4. 拾える場合、CollectableEntityをPayloadへ変換する。
  5. Field上のPrefabはPoolへ戻す。
  6. CollectionChangedEventを発行する。

2. 解放システム

項目仕様調整パラメータ検証観点
解放入力ボタンまたは一定条件で保持物を落とす。押しっぱなし、短押し、長押し、方向指定。直感的に落とせるか。
解放量全放出、一定割合、カテゴリ指定のどれかを選ぶ。放出割合、最小放出数、最大演出数。蓄積を解放している感覚があるか。
落下先DropZoneと方向から敵方向へ落とす。許容角度、補正強度、落下速度。狙った敵へ当てられるか。
演出物数実Payload数と表示Projectile数を分離する。表示上限、1ProjectileあたりPayload数。負荷と見た目の両立。
ヒット集計短時間の命中をHitBatchにまとめる。集計窓、ヒット倍率、最低ヒット数。大量ヒットが強く見えるか。

3. 敵攻撃ゲージシステム

敵は一定間隔で攻撃する。攻撃タイミングはゲージで視認できる。プレイヤーは物を当ててゲージを減らし、0にすると敵をダウンさせる。

状態条件処理プレイヤーへの意味
Charging通常時。ゲージが時間で増加する。急がないと敵攻撃を受ける。
Shieldedゲージの特定範囲。一部ダメージ減少を無効化する。落とすタイミングを考える。
Brokenゲージが0。敵がダウンへ移行する。攻撃チャンス。
Down一定時間。本体HPへダメージが通る。大量解放の本命。
Attackゲージ満タン。プレイヤーへ攻撃する。放置の失敗要素。

ゲージ計算の仮式

要素式補足
時間増加Gauge += ChargeSpeed * deltaTime敵ごとにChargeSpeedを持つ。
命中減少Gauge -= HitBatch.GaugeDamage * BarrierMultiplier無効範囲ではBarrierMultiplierが0または低値。
ダウン条件Gauge <= 0DownDurationを開始。
攻撃条件Gauge >= MaxGaugePlayerHealthへダメージ。

4. ダメージ無効範囲・バリア

バリア種類仕様プロトタイプ実装拡張案
ゲージ範囲無効ゲージが特定範囲にある間、減少を無効化。0.4〜0.6の範囲でGaugeDamageを0にする。範囲を敵ごとに複数持つ。
属性バリア特定属性以外のPayloadを軽減。赤/青/黄の1属性だけ試す。合体物だけ貫通可能。
ヒット数バリア一定Hit数以上のBatchのみ通す。10Hit未満を軽減。短時間大量ヒットをより重視。
重量バリア重いPayloadだけ通す。重量合計で判定。大きい物/合体物の価値を作る。

5. スーパーナダレタイム

短時間に大量の物を当てることで敵が大きく崩れ、通常以上に大量に落とせるチャンス状態へ入る。

項目仕様初期値案
発動条件一定時間内のHit数またはGaugeDamageが閾値を超える。2秒以内に20Hit。
継続時間敵がダウンし、物量が増える。5秒。
効果SpawnRate上昇、落下補正強化、ダメージ倍率、演出強化。SpawnRate x2、Hit倍率 x1.5。
終了条件時間終了、敵復帰、ボスフェーズ移行。Timer終了。
表示画面上部にカウント、色変化、SE、VFX。HUD + Camera揺れ。

6. 合体システム

集めた物を保持することで、特定の組み合わせが新しいPayloadへ変化する。合体は必須攻略ではなく、上手く集めたときのボーナスとして扱う。

仕様内容
発動タイミング収集直後、一定保持時間、解放直前のいずれか。プロトタイプでは収集直後に判定する。
必要素材CollectableDefinitionまたはCategory/Elementで指定する。
結果高威力Payload、バリア貫通Payload、広範囲Payloadなど。
UI合体候補がある場合、保持VisualやHUDで示す。
負担軽減レシピを覚えなくても、多く集めれば通常攻略できる。

レシピ例

素材結果効果狙い
軽い物 x 5圧縮玉Hit数は減るがGaugeDamageが高い。ゲージ削りを強める。
四角い物 x 3丸玉BufferCostが下がり、多く持てる。集める過程の変化。
赤属性 + 重い物貫通玉属性バリアを突破。敵バリアとの連動。
通常物 x 20大玉本体ダメージが高いが移動速度低下。溜めるリスクとリターン。

7. 形状変化システム

集めた物を転がすことで形状が変化し、収集しやすさや攻撃効果が変わる。形が変わるだけでは意味が薄いため、必ずゲーム上のメリットへ接続する。

変化条件効果プロトタイプ採用度
角が取れて丸くなる一定距離転がす。BufferCost低下、保持数増加。高。
圧縮される大量保持状態で一定時間移動。同数でも威力上昇。中。
巨大化同カテゴリを大量に集める。本体ダメージ増加、移動速度低下。低。コンセプトと衝突しやすい。
属性付与属性床を通る。バリア突破、ゲージ削り増加。高。

8. ステージ崩落システム

一方の敵を倒すと、その方向へ一瞬フィールドが傾き、物が雪崩れる。これにより、敵撃破が次の敵への巻き添えダメージに繋がる。

項目仕様調整パラメータ
発動条件敵撃破、またはDebug入力。敵種別、発動クールタイム。
傾き方向撃破した敵の方向へ傾く。角度、時間、戻り速度。
雪崩演出フィールド上の物が流れる。流量、速度、表示数。
巻き添え近くの敵へHitBatchを送る。範囲、ダメージ倍率、減衰。
復帰一定時間後に水平へ戻る。復帰時間、揺れ。

9. ボスステージギミック

ボスステージでは、通常の収集・解放に加えて、傾くフィールド、重量、時間制限、守る対象を入れる。通常ステージとの差別化を作るが、統合前は後回しにしてよい。

ギミック仕様目的最低実装
傾くフィールド一定間隔またはボス攻撃で床が傾く。位置取りと物の管理を強制する。左右にゆっくり傾く。
重量沈下物が多いと床が沈み、危険になる。集めすぎのリスクを作る。重量ゲージを表示。
お宝保護特定物が落ちるとペナルティ。落とすだけではない判断を作る。1種類のお宝だけ。
時間制限時間終了時のダメージ量で結果。ボス戦の区切りを作る。60秒。

10. 失敗条件・クリア条件

モードクリア条件失敗条件補足
通常プロト最奥のボスまたは指定敵を倒す。プレイヤーHPが0になる。アクションゲームとして分かりやすい。
ボス検証制限時間終了後、一定以上のダメージ。制限時間終了後、ダメージ不足。旧案の条件をボス専用に流用する。
デバッグ任意。任意。検証用に無敵/時間停止可。

優先度メカニクス理由
必須収集、保持、解放、命中、敵ゲージ、ダウン。企画の核を成立させるため。
高スーパーナダレタイム、HitBatch、HUD、カメラ演出。大量に当てる気持ちよさを強化するため。
中合体、属性床、バリア。「どう集めるか」を作るため。
中ステージ崩落。敵撃破の連鎖を作るため。
