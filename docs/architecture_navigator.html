実装時の見る順番

  1. まず用途別プリセットで対象範囲を絞る
  2. 対象カードの「責務」「所有者」「関連ファイル」を確認する
  3. 書き換え可否が必要なら所有者一覧を参照する
  4. クラスを実装する際は関連ファイルのパスをそのまま辿る
  5. 依存先を増やす前に、GameMediator / サービス経由かを確認する
純C#クラスはロジック、MonoBehaviourは表示・入力、ScriptableObjectは定義データという分離を前提に閲覧する想定です。
